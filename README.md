# Student Grade Tracker
This project is part of my Java Development internship at CodeAlpha.

## Description
A simple Java program that allows teachers to enter student grades and automatically calculates:
* Average Grade
* Highest Grade
* Lowest Grade

## How to Run
1. Compile: `javac StudentGradeTracker.java`
2. Run: `java StudentGradeTracker`
